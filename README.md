# Boyfriend Day — Exact Style Recreation ❤️

This version recreates the visual structure from the supplied screen recording:
- soft peach/pink scrapbook background
- stacked paper title cards
- handwritten-style headings
- message card
- six colored "few reasons" notes
- polaroid memory section
- letter section
- thank-you section
- window/peek section
- final Boyfriend Day screen
- smooth section-to-section buttons
- subtle floating hearts

## Run
Open `index.html` in VS Code with Live Server, or simply open it in a browser.

## Edit text
Almost all text is directly in `index.html`.

The requested replacement is already present:
"That you love me sooo much, which I love it"

## Add your photos later
In the memory section, replace the `.photo-placeholder` with an image:
<img src="assets/photo1.jpg" alt="Memory">

Create an `assets` folder and put your photos there.

This build intentionally does NOT include your personal photos yet, as requested.
